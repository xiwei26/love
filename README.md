# 像素童话求婚网站

这是一个基于 `Vite + TypeScript` 的单页求婚网站。

打开后会先显示“点击开启音乐与童话”，点击后开始自动播放像素剧情，播放到宝箱时停住；再次点击宝箱进入最终求婚画面。

## 运行环境

- Node.js 20.19+ 或 22.12+
- npm

## 本地运行

第一次运行先安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

启动后在浏览器打开终端里显示的本地地址，通常是：

```text
http://localhost:5173
```

## 观看流程

1. 打开页面
2. 点击“点击开启音乐与童话”
3. 等剧情自动播放到宝箱场景
4. 点击宝箱，进入最终求婚画面

如果你只是想快速看完整流程，可以用测试模式打开：

```text
http://localhost:5173/?testMode=1
```

这个模式会把剧情时间大幅缩短，方便预览。

## 主要目录

- `src/`：页面逻辑、场景渲染、样式
- `public/photos/`：回忆照片
- `public/sprites/`：统一像素风角色、恶龙、宝箱、戒指与爱心素材
- `public/audio/`：背景音乐
- `tests/`：单元测试和 e2e 测试
- `docs/`：设计稿和实现计划

## 视觉与移动端适配

- 求婚终章加入大幅像素爱心气球，分批沿两侧缓缓上浮并轻轻摇摆；气球位于人物和文字后方，手机上减少数量，减少动态效果模式下静态展示。

- 回忆照片按原始宽高比显示，不拉伸、不裁掉人物；横屏和竖屏使用不同的照片排布，旋转屏幕时重新计算透视位置。
- 保留五幅像素童话背景，移除重复的几何平台、地面和幕布。字幕、人物、求婚文字与操作按钮分别留有空间。
- 终章以两位主角为中心，宝箱缩小放到侧边，戒指单独展示；竖屏提示不会覆盖按钮，开始播放后自动隐藏。
- 角色、恶龙和宝箱使用统一的暖金色像素素材。救援动画只播放一次并保持结束状态，尊重系统的减少动态效果设置。

### 素材维护

当前使用的素材为 `public/sprites/storybook-*.png`。生成提示词与原始图集保存在 `garden-gpt-image-2/prompt/unified-sprites-20260912.md` 和 `garden-gpt-image-2/image/unified-sprites-20260912.png`。背景与真实照片保留原文件。

如需从这份原始图集重新导出透明素材，在安装开发依赖及 Playwright Chromium 后运行：

```bash
node scripts/prepare-sprites.mjs
```

脚本按图集位置导出素材，清理中性棋盘格底与浅色边缘，统一人物比例和脚底基线。更换原始图集时需要同步检查裁切区域。

浏览器回归覆盖电脑、手机横屏与手机竖屏的终章构图及按钮点击；照片布局测试检查原始比例、视野边界与相互遮挡。
